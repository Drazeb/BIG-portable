# Sources des spécimens de référence — Famille 06 Flat illustré coloré (variante cinéma)

## Avertissement honnêteté

Les 3 spécimens PNG dans ce dossier ne sont **pas** des captures de marques réelles. Ce sont des **interprétations SVG générées par Claude** (lors de la PoC `icon-system`, 2026-05-27) qui incarnent les signatures pro 2024-2026 documentées dans la slop sheet `slop-sheets/06-flat-illustre.md`.

**Pourquoi cette approche** :
- Évite tout problème de copyright sur des assets de marques existantes
- Permet une cohérence visuelle (mêmes proportions, mêmes contraintes formelles) entre les références
- Sert exclusivement de référence visuelle pour le gate visuel multimodal du PoC

**Choix de la variante cinéma sombre** : pertinente pour la session Camille 0513 (concept "Le Phare de Ralliement" — Dark Mode Cinema × Exaggerated Minimalism, palette nuit d'indigo + laiton). Pour une autre session avec palette claire, générer des spécimens variant clair.
