# Sources des spécimens de référence — Famille 04 Gravure / linocut

## Avertissement honnêteté

Les 3 spécimens PNG dans ce dossier ne sont **pas** des captures de marques réelles. Ce sont des **interprétations SVG générées par Claude** (lors de la PoC `icon-system`, 2026-05-27) qui incarnent les signatures pro 2024-2026 documentées dans la slop sheet `slop-sheets/04-gravure.md`.

**Pourquoi cette approche** :
- Évite tout problème de copyright sur des assets de marques existantes
- Permet une cohérence visuelle (mêmes proportions, mêmes contraintes formelles) entre les références
- Sert exclusivement de référence visuelle pour le gate visuel multimodal du PoC

**À remplacer si possible** : par des captures réelles des marques nommées ci-dessous, prises avec autorisation ou usage éditorial limité (recherche interne).
