# 08 — Brutaliste / ASCII

## Nom canonique et alias
- **Nom canonique** : Brutaliste / ASCII
- **Alias usuels** : web brutalism, terminal aesthetic, ASCII art, monospace icons, anti-design icons, raw web
- **ID stable** : `08-brutaliste`

## Époque d'origine et revivals
- **Origine** : terminal Unix années 1970s + ASCII art BBS années 1980s + brutalisme architectural 1950-1970
- **Revival web** : 2018-2026 — Mike Mai, Bobby Berry, Dia Browser, Substack writer culture, Are.na (partiel)
- **Codes contemporains** : monospace + aplats noirs bruts + caractères Unicode utilisés graphiquement

## Traits formels
- **Stroke** : pur trait monospace, ou caractères Unicode (`█`, `▓`, `░`, `┃`, `╋`)
- **Fill** : aplats noirs francs, aucun anti-aliasing
- **Géométrie** : grille caractère stricte, pas de courbes (tout en angles droits ou caractères)
- **Texture** : la grille typographique EST la texture
- **Composition** : asymétrie assumée, refus du centrage parfait, "raw" web

## Marques contemporaines qui l'emploient (2024-2026)
1. **Mike Mai** — site personnel (référence brutalism contemporain, 2023-2025)
2. **Bobby Berry** — portfolios brutalist (2024)
3. **Dia Browser** — interface partiellement brutalist (2025)
4. **Sentry** — sections doc avec accents terminal (2024-2025)
5. **MUD** — design system gaming (2024-2025, brutalist tendance)

## Couleurs natives
- **Palette principale** : noir / blanc / vert phosphore (héritage terminal) / orange terminal
- **Bichromie stricte** : 2 couleurs MAX, en contraste maximal
- **Mode sombre natif** : signature historique (fond noir + texte blanc/vert)
- **Pas d'accent décoratif** : la contrainte est le médium

## Formats natifs en stack Claude Code
- **`<pre>` HTML avec font monospace** : IBM Plex Mono, JetBrains Mono, GT Pressura Mono
- **Caractères Unicode utilisés graphiquement** : `█▓░│─┃╋╳╱╲`
- **CSS minimal** : `font-family: monospace; white-space: pre`
- **SVG rect possible** : pour les icônes plus précises, sur grille stricte
- **shape-rendering="crispEdges"** : si SVG, pas d'anti-aliasing

## Grain naturel (où la famille brille)
- Marques tech-pointues / dev tools / infrastructure
- Marques counterculture qui refusent le polished SaaS
- Identités personnelles techniques (sites de devs / chercheurs)
- Marques qui revendiquent une signature graphique forte
- Newsletters tech, blogs techniques, doc API alternative

## Compatibilités concept (tons)
- **Brut / contre-culture** : excellent (signature native)
- **Tech-pointue / dev** : excellent
- **Indie / artisanal numérique** : excellent
- **Anti-corporate** : excellent
- **Minimalisme radical** : excellent
- **Geek / hacker** : excellent
- **Sérieux institutional** : très faible (anti)
- **Premium / luxe** : très faible
- **Ludique / accessible** : moyen (peut basculer si bien fait)
- **Cinématographique** : moyen
- **Artisanal physique / patrimoine** : faible (médium intrinsèquement numérique)

## Incompatibilités évidentes
- Marques B2C grand public → illisible pour la cible
- Marques luxe → contradiction totale de codes
- Marques wellness → trop agressif
- Hero éditorial narratif → la brutalism casse le récit
- Sites qui visent une accessibilité large → barrière de lecture
