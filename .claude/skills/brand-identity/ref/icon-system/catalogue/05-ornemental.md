# 05 — Ornemental (art déco / nouveau / blason)

## Nom canonique et alias
- **Nom canonique** : Ornemental
- **Alias usuels** : art déco icons, art nouveau, blason, filigrane, monogramme, lettering ornemental, heraldic, decorative pictogram
- **ID stable** : `05-ornemental`

## Époque d'origine et revivals
- **Origine** : héraldique médiévale → art nouveau (1890-1910, Mucha, Klimt) → art déco (1920-1940, Cassandre, Erté)
- **Revival mainstream** : 2018-2026 — Pentagram identities luxury (Cunard, Cartier), COLLINS (Spotify Wrapped 2024-2025), studios Mucho / Mast Brothers
- **Codes contemporains** : géométrie stricte + symétries + accents typographiques rigoureux

## Traits formels
- **Stroke** : très fin (0.5-1px) pour le filigrane, ou très épais (3-4px) pour la silhouette pleine
- **Fill** : aplats noirs ou cuivre/or, jamais grisaille
- **Géométrie** : symétries axiales / radiales strictes, coins coupés (chamfered), géométrie sacrée
- **Texture** : aucune texture organique — la richesse vient de la géométrie elle-même
- **Composition** : centrage solennel, hiérarchies emboîtées (motif central + cadre + motifs satellites)

## Marques contemporaines qui l'emploient (2024-2026)
1. **Cartier** — identité digitale (2024-2025)
2. **Cunard** — rebrand Pentagram 2024 (héritage maritime)
3. **Mast Brothers** — packaging chocolat (depuis 2018, ré-amplifié 2024)
4. **Hermès Heritage** — sections savoir-faire 2024-2025
5. **Aesop Athens / Tokyo collections** — pictogrammes spéciaux (2025)

## Couleurs natives
- **Palette principale** : noir / crème / accents métalliques (cuivre, or, bronze patiné)
- **Bichromie** : noir + 1 couleur métallique noble, jamais "or jaune vif" (toujours patiné)
- **Mode sombre** : crème sur fond charbon + accent cuivre — registre cérémonial moderne
- **Pas de couleurs vives** : registre noble et retenu

## Formats natifs en stack Claude Code
- **SVG inline avec symétries** : transforms `scale(-1, 1)` pour les symétries axiales
- **Géométrie composite** : polygones imbriqués, courbes Bézier rigoureuses
- **Pattern circulaires** : `<pattern>` ou utilisation de `<g>` avec rotation
- **Stroke variable** : 2-3 paths avec stroke-widths différents pour la hiérarchie
- **Pas de filter, pas de gradient** : pureté géométrique

## Grain naturel (où la famille brille)
- Hero éditorial cérémonial (annonces, lancements, événements)
- Marques luxe / héritage / hospitalité haut de gamme
- Marques institutionnelles qui revendiquent une histoire longue
- Wedding, hospitality, spiritueux premium, montres
- Concepts qui demandent solennité, durabilité, autorité tranquille

## Compatibilités concept (tons)
- **Cérémonial / luxe** : excellent (signature native)
- **Héritage / patrimoine** : excellent
- **Premium retenu** : excellent
- **Méthodique / rigoureux** : très bon (symétries strictes)
- **Autorité institutionnelle** : très bon
- **Sérieux** : très bon
- **Cinématographique** : bon (clair-obscur possible)
- **Tech / outil moderne** : faible (anachronique)
- **Ludique / accessible** : très faible
- **Brut / contre-culture** : très faible (= l'establishment incarné)
- **Artisanal contemporain** : moyen (plus institutionnel qu'artisanal)

## Incompatibilités évidentes
- Marques B2B SaaS modernes → clash temporel
- Marques jeunes (kids, gen Z) → trop institutional
- Marques counterculture → opposé total
- Concepts dynamiques / disruption → la stabilité ornementale contredit le mouvement
