# Brief Alpha — Template des 14 Points d'Input

Ce document définit les **14 points de données critiques** que le BIG doit ingérer pour créer une identité de marque. Chaque point a un impact direct sur les décisions de Direction Artistique.

---

## MOTEUR 1 : LOGIQUE BUSINESS (Le Socle)

### 01. Produit & Catégorie (Market Category)
- **Quoi** : Identification précise du type de solution et de sa case mentale sur le marché
- **Format attendu** : "C'est une [Catégorie] qui permet de [Action principale]"
- **Impact DA** : Définit les codes visuels de base (ex: Fintech → sécurité ≠ Gaming → énergie)
- **Score confiance si absent** : CRITIQUE — impossible de démarrer sans

### 02. Alternatives Compétitives (Status Quo)
- **Quoi** : Ce que l'utilisateur fait aujourd'hui sans le produit
- **Format attendu** : 2-3 noms de concurrents ou méthodes remplacées
- **Impact DA** : Permet d'identifier le "Ventre Mou" sectoriel pour s'en éloigner visuellement
- **Score confiance si absent** : ÉLEVÉ — empêche le calibrage du Curseur B

### 03. Killer Feature & Bénéfice "Wow"
- **Quoi** : La fonctionnalité unique qui déclenche la vente + le gain concret
- **Format attendu** : Descriptif technique court + bénéfice émotionnel/financier
- **Impact DA** : Élément central du Composant Témoin et sujet des premières illustrations
- **Score confiance si absent** : ÉLEVÉ — le Showroom perd son ancrage

### 04. ICP & Douleur Critique (Pain Point)
- **Quoi** : Le profil du décideur et son problème le plus angoissant
- **Format attendu** : Titre de poste + peur réelle
- **Impact DA** : Oriente la psychologie des couleurs et le Character Design
- **Score confiance si absent** : ÉLEVÉ — les choix émotionnels deviennent arbitraires

### 05. Objections Majeures (Le Mur)
- **Quoi** : Les raisons pour lesquelles un prospect dit "non"
- **Format attendu** : 2-3 freins (ex: "Trop cher", "Trop complexe")
- **Impact DA** : Le design doit "vendre par le regard" en simplifiant visuellement ces frictions
- **Score confiance si absent** : MOYEN — on peut extrapoler mais avec risque

### 06. Business Model & Pricing
- **Quoi** : Positionnement tarifaire et cycle de vente
- **Format attendu** : Ordre de grandeur (ex: 29€/mois vs 20k€/an)
- **Impact DA** : Prix élevé → DA "High-Trust" ; Prix faible → DA "Action/Vibrante"
- **Score confiance si absent** : MOYEN — influence le niveau de polish attendu

### 07. Social Proof & Preuves de Confiance
- **Quoi** : Éléments prouvant que ça marche (témoignages, logos, certifs)
- **Format attendu** : Type d'assets disponibles
- **Impact DA** : Influence les sections "Trust" et l'intégration de réassurance
- **Score confiance si absent** : FAIBLE — les sections Trust peuvent être génériques

---

## MOTEUR 2 : STRATÉGIE DE MARQUE (L'Émergence)

### 08. Le Point de Rupture (The Zag)
- **Quoi** : La conviction radicale qui différencie l'entreprise
- **Format attendu** : "À l'opposé de [Marché], nous pensons que [Conviction]"
- **Impact DA** : Carburant du Curseur B (Différenciation ZAG)
- **Score confiance si absent** : CRITIQUE — sans Zag, pas de différenciation possible

### 09. Tension de Marque (Le Paradoxe)
- **Quoi** : L'union de deux attributs contradictoires pour créer une identité unique
- **Format attendu** : Deux attributs opposés (ex: "Élégance" + "Brutalité")
- **Impact DA** : Évite les designs génériques en forçant une synthèse visuelle inattendue
- **Score confiance si absent** : CRITIQUE — cœur créatif de toute l'identité

### 10. Attitude (Tone of Voice)
- **Quoi** : Personnalité verbale et comportementale de la marque
- **Format attendu** : 3 adjectifs de tempérament
- **Impact DA** : Guide le choix des polices, le rythme éditorial et le "vibe" général
- **Score confiance si absent** : ÉLEVÉ — la typo et le Voice Block dépendent directement

### 11. Ancre de Référence (Analogie)
- **Quoi** : Raccourci mental pour situer l'ambition de la marque
- **Format attendu** : "Le [Marque Mondiale] du [Secteur]"
- **Impact DA** : Donne une direction sur le niveau de finition et la posture
- **Score confiance si absent** : MOYEN — utile mais pas bloquant

### 12. Univers Narratif & Choix Figuratif
- **Quoi** : Préférence pour le mode d'expression des concepts
- **Format attendu** : "Humains/personnages" OU "Formes abstraites/techniques"
- **Impact DA** : Alimente le Point 10 de l'Output (Illustration Narrative)
- **Score confiance si absent** : MOYEN — peut être proposé par le DA

### 13. Contraintes & Assets Techniques
- **Quoi** : Périmètre matériel du projet (Nom, Logo existant, Supports prioritaires)
- **Format attendu** : Détails sur les livrables et contraintes techniques
- **Impact DA** : Définit les contraintes de scalabilité et les délivrables
- **Score confiance si absent** : MOYEN — on peut travailler avec des hypothèses raisonnables

### 14. Le Verdict du Succès (Émotion Unique)
- **Quoi** : L'émotion unique que le client doit ressentir en 5 secondes
- **Format attendu** : Un mot unique (ex: "Évidence", "Harmonie", "Puissance")
- **Impact DA** : Filtre final de validation pour chaque composant et illustration
- **Score confiance si absent** : ÉLEVÉ — sans ce filtre, la validation finale est subjective

---

## SCORING DE CONFIANCE

### Calcul du score global
- Chaque point reçoit un score de 0 à 100% basé sur la qualité et la précision de l'input
- Pondération : CRITIQUE (×3), ÉLEVÉ (×2), MOYEN (×1), FAIBLE (×0.5)
- **Score global = somme pondérée / somme des poids × 100**

### Seuils
- **≥ 90%** : Feu vert pour Phase 2
- **70-89%** : Questions ciblées sur les points déficients, puis recalcul
- **< 70%** : Brief insuffisant — guidage interactif complet recommandé
