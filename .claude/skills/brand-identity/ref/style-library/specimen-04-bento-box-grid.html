L'information dense organisée en tuiles modulaires de tailles variables — chaque module porte une donnée distincte, scannable d'un seul regard. Une tuile domine, les autres orbitent : la hiérarchie est dans la proportion, pas dans le poids typographique.

La grille asymétrique en action

SIGNATURE #1

Le Bento ne vit pas dans la grille 3×3 régulière — c'est ce qui le différencie d'un mur de cards Pinterest. Une tuile dominante (2-3× plus grande) capte le regard en premier, puis l'œil descend par paliers vers les satellites de tailles décroissantes. Les contenus sont délibérément hétérogènes : un chiffre, un graphe, une citation, une illustration.

05 — Densité contrôlée

Anatomie d'une tuile, règles d'or

SIGNATURE #2

Une tuile Bento n'est pas une "card" générique. Elle a un rôle précis dans la composition d'ensemble — USP, social proof, métrique, CTA secondaire. Le border-radius, les paddings et la teinte de fond sont cohérents entre toutes les tuiles, mais leur contenu est radicalement différent.

Tuile USP — exemple
Réduisez de 6 jours le délai entre data brute et décision opérationnelle.

Une tuile = une promesse. Le copy y est dense mais autosuffisant — la tuile doit pouvoir être lue isolément, sans contexte des voisines. C'est la condition de la scannabilité.

  • border-radius : 22px (cohérent sur toute la grille)
  • padding : 28-32px (jamais < 22px)
  • fond : teinté ou neutre, jamais blanc pur
  • bordure : 1px hairline ou aucune (pas d'ombre)

Les 4 règles non négociables

01

Tailles variées obligatoires. Une grille 3×3 uniforme = anti-bento. Au minimum une tuile 2×2 entourée de tuiles 1×1 ou 2×1.

02

Contenus hétérogènes. Chiffre + texte + graphe + citation. Si toutes les tuiles ont icône+titre+texte, c'est un mur de cards déguisé.

03

Border-radius cohérent. Si la dominante est à 22px, toutes les autres aussi. L'incohérence trahit le copier-coller.

04

Pas de gradient violet. Le purple-to-blue dans une tuile est le marqueur AI-slop le plus daté de 2025.

ATMOSPHÈRE

Mode d'emploi

Quand utiliser ce style

SaaS B2B, dashboards analytiques, plateformes de données, pages produit Tech qui doivent montrer beaucoup d'USP en un seul écran. Idéal quand la marque doit dire "nous faisons N choses, et chacune mérite votre attention".

Quand l'éviter

Édition culturelle, marques émotionnelles, parfumeries, sites artistiques. Le Bento parle data — il refroidit ce qui devrait chauffer. Évitez aussi en 2026 si la marque cherche à se différencier visuellement : 67% des SaaS l'utilisent déjà, le risque de banalisation est élevé.
