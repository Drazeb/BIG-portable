Micro-interactions.

Voir le système

Trente pour cent du score Awwwards repose sur l'usabilité, dont les hover states, le comportement du curseur et les transitions. Ce style ne se lit pas — il se ressent à la milliseconde.

Helio — Système d'interactions

01 / Hover

Hover states intentionnels.

Pas de translation verticale au survol — le marqueur le plus générique du web. Ici, le hover modifie simultanément la couleur de fond, du texte, du label et révèle une ligne signal depuis la gauche. Multi-property, timing identique, easing nommé. Le geste est lu, pas subi.

État · base

Pas de translateY.

Le hover change la couleur, pas la position. Le composant reste à sa place — l'œil ne saute pas, la grille tient.

État · base

Multi-property.

Background, color, label, ligne signal : quatre propriétés transitionnent ensemble, à 240ms, sur la même courbe expo.

État · base

Easing nommé.

Le système n'utilise jamais ease. Tous les hover passent par --ease-out-expo, partagé.

02 / Easing

Un catalogue d'easings, pas une valeur par composant.

Les courbes sont nommées et partagées — survolez une ligne pour voir la bille parcourir la piste. La cohérence du timing dans tout le système est ce qui distingue un site primé d'un site générique.

--ease-out-expo
cubic-bezier(0.19, 1, 0.22, 1)
240ms
--ease-out-back

03 / Contraste

Slop générique vs geste intentionnel.

À gauche, le pattern le plus copié du web : transform: translateY(-3px) sur transition: all ease. À droite, le même bouton avec un système nommé. Survolez les deux pour ressentir l'écart.

À éviter · slop

translateY au hover.

Effet "carte qui flotte". Inflation de l'easing par défaut. Le système n'a aucune cohérence : chaque composant choisit son propre timing. Marqueur des landings 2017-2020.

Intentionnel

Multi-property + easing nommé.

Background, couleur, bordure transitionnent ensemble sur --ease-out-expo à 240ms. Le composant ne bouge pas — il change d'état. Lisible, partagé, débuggable.

04 / Atmosphère

Le silence avant le geste.

L'atmosphère du style est calme — graphite, cream, un seul signal vermillion. La densité visuelle reste basse pour que le mouvement, quand il vient, devienne lisible. C'est l'inverse du maximalisme.

Quand l'utiliser

Outils SaaS premium, plateformes professionnelles, marques tech qui veulent signaler de la précision. Linear, Arc, Vercel, GSAP. Score Awwwards 8.5+ sur la composante Usability.

Quand l'éviter

Édition culturelle expressive, sites événementiels à fort impact émotionnel, identités où le geste doit être théâtral plutôt que précis. Le style est neutre par discipline — c'est sa force et sa limite.
