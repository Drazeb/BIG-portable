Signature 01 · Default Web

Le HTML brut redevient un statement.

Le style Anti-Polish revendique la mise en page "ungestaltet" — Times New Roman par défaut, liens bleu CIE 0000EE, liens visités violet 551A8B, <hr> gris. Pas par paresse, par position : le design system d'aujourd'hui est devenu une paraphrase polie de l'algorithme.

Le navigateur sans CSS est l'opposé exact du dashboard SaaS gradient violet. Là où l'AI optimise vers le centre, ce style sort par le bord — et ce bord est lisible, archivable, indestructible.

Signature 02 · Type non-poli

Une condensée brute + un monospace système.

La typo de ce style vient des Une de tabloïds, des fanzines photocopiés, des README.txt. Anton, Impact, Archivo Black, Bagel Fat One pour les titres ; Space Mono, JetBrains Mono, Courier pour le corps. Jamais Inter, jamais le pairing "moderne" Inter+Inter Display.

Le marqueur fluo et le trait rouge de relecture sont la voix de l'éditeur — visible, fautive, en cours. La typo n'est pas figée dans une charte, elle est attrapée en train d'être corrigée.

Signature 03 · Stylos disponibles

Les couleurs sont celles qu'on a sur le bureau.

Pas de palette générée, pas de design tokens versionnés. Du noir d'encre photocopie (jamais #000000 — trop écran), du jaune highlighter Stabilo, du rouge marker Sharpie, du bleu Bic stylo, du papier laser jauni. Six couleurs maximum, choisies parce qu'elles existent dans une trousse réelle.

Aucun gradient. Aucun violet `#6366f1`. Aucune ombre `0 0 24px rgba(99,102,241,0.3)`. Les ombres sont des offsets noirs durs (5px 6px 0) — l'ombre d'une feuille posée à plat, pas d'un vaisseau spatial qui flotte.

Atmosphère · Quand utiliser

Là où le bord rugueux devient le seul vrai signal.

  • Édition indépendante, fanzines, revues critiques, médias d'opinion
  • Marques culturelles et musicales qui revendiquent l'underground
  • Studios créatifs qui refusent d'être confondus avec leurs clients
  • Manifestes, prises de position éditoriales, archives militantes
  • Fintech, banque, assurance — la rugosité passe pour amateurisme
  • SaaS B2B, dashboards data — l'utilisateur a besoin de calme, pas de friction
  • Quand le client confond "raw" avec "j'ai pas eu le temps"
