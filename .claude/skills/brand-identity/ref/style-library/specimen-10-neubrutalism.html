Signature 1 / Bordure & ombre offset

La grammaire : 3px de bordure, 6px d'ombre, zéro flou.

Chaque bloc est posé physiquement sur la page. La bordure noire (2-4px) délimite le territoire ; l'ombre offset (4-8px de décalage, blur 0) le décolle. C'est l'inverse du shadow doux SaaS — ici l'ombre est un trait, pas un halo.

Signature 2 / Typographie assumée

Une display BLACK, jamais elegant.

Le Neubrutalism rejette les serifs élégantes et les sans-serifs neutres (Inter, Roboto = interdits par défaut). On choisit une display noire ou expressive (Archivo Black, Space Grotesk Bold, Druk) qui pèse sur la page et pose le ton avant même qu'on lise.

Signature 3 / Boutons-objets

Le bouton n'est pas un état CSS. C'est un objet.

Dans le Neubrutalism, un bouton est un bloc avec ses bords, son ombre et sa couleur de fond saturée — pas un rectangle teint qui change d'opacité. L'utilisateur perçoit qu'il peut le pousser physiquement.

L'atmosphère : tableau d'atelier, pas dashboard d'entreprise.

Les blocs se chevauchent légèrement, certains sont rotatés de 1 à 3 degrés. L'ensemble respire le mood-board imprimé, le post-it punaisé, l'autocollant collé un peu de travers. Le fond crème (jamais blanc pur) ajoute la chaleur d'un papier, pas la froideur d'un écran.

Quand utiliser ce style

Outils créatifs (Figma plugins, presets, packs), creator economy, plateformes Gen Z, marques anti-template qui veulent stopper le scroll. Aussi : startups produit qui veulent se distinguer du SaaS bleu-violet générique.

Quand l'éviter

Banque, assurance, santé, juridique : le style transmet ludique et anti-établi, ce qui contredit le besoin de sérieux institutionnel. Aussi : luxe contemplatif (le bruit visuel tue le silence) et éditorial culturel haut de gamme.
