# Rapport — angle mort potentiel du catalogue styles BIG sur le pattern « Painterly Editorial Illustration »

**Date** : 2026-05-10
**Auteur** : session visual-prompt Camille Phare de Ralliement
**Destinataire** : session ayant développé `styles-bibliotheque.md`
**Statut** : observation à arbitrer (pas de modification appliquée)

---

## Contexte de l'observation

Lors d'une session de génération visuelle pour le concept Camille « Phare de Ralliement » (style retenu = **Gradient Mesh / Aurora Evolved PUR** dans le brief styliste), l'utilisateur a partagé 5 sites élite contemporains pour comparer notre direction visuelle :

1. https://www.structured.money/
2. https://www.solidroad.com/
3. https://www.generalintelligencecompany.com/
4. https://duna.com/
5. https://www.vale.legal/

L'analyse visuelle des hero a révélé qu'aucun de ces sites n'utilise du **Gradient Mesh / Aurora Evolved au sens strict** (les blobs flous abstraits style Stripe/Vercel). À la place, **3 sur 5** (solidroad, GIC, duna) utilisent un pattern qui ne semble pas exactement correspondre à un style nommé du catalogue BIG.

## Constat 1 — Confusion initiale sur Storytelling-Driven (#27)

**Erreur de classification temporaire** : j'ai d'abord classé ces hero comme « Storytelling-Driven » (#27).

**Vérification dans la fiche officielle** : Storytelling-Driven (#27) est défini comme **scroll narrative + cinematic experiences** (sections révélées progressivement, camera-like transitions, audio optionnel, pacing intentionnel). C'est une **logique d'animation/scroll**, pas un pattern d'illustration figurative en hero.

**Référence culturelle de #27** : The Goonies (Joseph Berry), Blue Desert (Adoratorio), Awwwards Storytelling winners.

→ Storytelling-Driven ne couvre PAS le pattern hero illustration painterly statique.

## Constat 2 — Niveaux d'abstraction du catalogue BIG

Le catalogue BIG mélange plusieurs niveaux d'abstraction :

| Niveau | Exemples |
|---|---|
| **Styles transversaux complets** (orientent grille + typo + palette + composants + interactions) | Swiss Modernism 2.0 (#50), Brutalism (#4), Cyberpunk UI (#41), Memphis Design (#44), Dark Mode Cinema (#7) |
| **Patterns ou effets transversaux partiels** (orientent un aspect dominant) | Hypertypography, Glassmorphism (#3), Bento Box Grid (#39), Gradient Mesh / Aurora Evolved (#65), Hypertypography |
| **Logiques d'animation/interaction** | Storytelling-Driven (#27), Motion-Driven (#15), Parallax Storytelling (#49), Immersive Scroll Narrative |

Le pattern « hero illustration painterly figurative » observé sur duna.com / solidroad.com / GIC se positionne au niveau **pattern partiellement transversal** (oriente le hero + le mood global) sans être un système complet à la Swiss Modernism.

## Constat 3 — Potentiel angle mort sur Anti-AI Crafting

La fiche officielle **Anti-AI Crafting / Craft-Core** est définie comme :

> Designers are putting their hands back on the work — literally. Photographie 35mm grain argentique. Textures analogiques RÉELLES (tissu, argile, liège, bactéries cultivées). Lumière naturelle physique. Imperfections visibles du matériau. Compositions qui montrent le geste humain.
>
> Différent de Naïve Design : utilise de vrais matériaux physiques photographiés (≠ simulation digitale d'imperfection).
>
> Références culturelles : Burberry Cross-Stitch Knight Life campaign · Madalena Studio pour Crucible (bacteria cork logo) · OpenAI ChatGPT 2025

Cette définition est **centrée sur la photographie de matériaux physiques réels**.

**Or les hero observés sur duna.com / solidroad.com / GIC ne sont PAS des photos de matériaux physiques** — ce sont **des illustrations painterly digitales** (numériques, peintes ou rendues, parfois IA, parfois illustrateur indé) avec :
- Multi-plans étagés smooth
- Atmosphère graduée
- Grain matière éditorial (offset / Risograph / Kodak Portra digital)
- Style proche Inio Asano, Tatsuro Kiuchi, Owen Davey, Makoto Shinkai-light, Studio Ghibli-modern

**Décalage** : Anti-AI Crafting parle de **photo matière physique réelle** ; le pattern observé est de **l'illustration peinte digitale anti-polish**. Les deux relèvent de la même intention philosophique (rejet du flat AI clean) mais utilisent des médiums différents.

## Hypothèse soumise à arbitrage

Le catalogue BIG pourrait éventuellement bénéficier de :

### Option 1 — Ajouter un nouveau style « Painterly Editorial Illustration / Editorial Hero Illustration »

Caractéristiques proposées :
- Illustration painterly figurative digitale (ou IA painterly)
- Multi-plans atmospheric depth
- Grain matière éditorial (offset / Riso / Kodak Portra grain)
- Composition narrative (raconte un univers / un voyage / un mood)
- Palette riche (peut être pastel duna-like ou dark Asano-like)
- Style proche : Tatsuro Kiuchi, Owen Davey, Inio Asano, Daniel Liévano, Olivia Fields
- Registre : Crafty / Cinématographique / Éditorial

Référence culturelles candidates :
- duna.com (hero pastel atmospheric painterly)
- solidroad.com (hero illustratif Studio Ghibli-light)
- generalintelligencecompany.com (digital painting figuratif détaillé)
- New Yorker editorial covers
- Publication design contemporaine (Bloomberg Green illustration, etc.)

### Option 2 — Raffiner la fiche Anti-AI Crafting / Craft-Core existante

Élargir explicitement la définition pour qu'elle couvre **deux variantes** :
- **Variante A — Photo matière physique** (la définition actuelle : tissu, argile, liège, bactéries)
- **Variante B — Illustration painterly digitale anti-polish** (le pattern observé : painterly digital editorial illustration)

Avec une note explicite que les deux variantes partagent l'intention philosophique commune (rejet du flat AI clean, retour de la matière), mais utilisent des médiums différents (photo vs illustration peinte).

### Option 3 — Ne rien changer

Considérer que le pattern observé est suffisamment couvert par la combinaison **Anti-AI Crafting (étendu mentalement) + Editorial Grid + Quiet Luxury Digital + Dark Mode Cinema** selon les cas, sans nécessiter de fiche dédiée.

Argument en faveur du non-changement : le catalogue BIG est déjà conséquent (66+ styles), et la mécanique mix dominant × modulateur permet déjà de combiner pour produire ce pattern.

## Argument transverse — pertinence de l'observation

Le pattern « hero illustration painterly figurative » est **clairement un trend dominant** sur les sites élite 2024-2026, observable au-delà des 3 sites listés (Bloomberg Green, certaines startups SaaS premium, sites portfolio agences créatives). Il mérite probablement d'être **explicitement identifiable** dans le catalogue BIG, soit comme nouvelle entrée, soit comme variante explicite d'une entrée existante.

L'observation est issue d'un cas réel : pour le concept Camille, le brief styliste a prescrit **Gradient Mesh / Aurora Evolved PUR** mais les itérations de production ont naturellement glissé vers un pattern différent (paysage atmospheric multi-plans painterly avec foyer lumineux atténué). Si une fiche **« Painterly Editorial Illustration »** existait, elle aurait probablement été retenue par le styliste à la place de Gradient Mesh, ou en mix dominant × modulateur Gradient Mesh.

## Recommandation honnête

**Mon avis (neutre, à arbitrer par la session experte)** :

- **Option 2 (raffiner Anti-AI Crafting)** semble le meilleur compromis. Cette fiche est philosophiquement le bon endroit (intention « designers back to materials, anti-flat-AI »), il suffit d'élargir explicitement la définition pour couvrir les deux variantes (photo matière + illustration painterly digitale).

- **Option 1 (nouveau style)** serait plus précis mais alourdit le catalogue.

- **Option 3 (rien changer)** est défendable mais laisse l'angle mort sur les sessions futures.

Le choix d'arbitrage relève de la session ayant développé le catalogue.
