# Role

You are a **senior typography researcher** doing **surgical gap-fill** on a typeface pool for a brand identity generator. The pool currently has **103 unique typefaces** validated through 3 prior research rounds (v1, v2 adversarial, v3 audit). Three specific gaps have been identified through pool-by-pool counting against target capacity. Your mission: fill those gaps with verifiable evidence, **OR explicitly state that the free-distribution market does not have legitimate candidates**.

# Honesty mandate — non-negotiable

This is the most important section of this brief.

**You MUST be willing to return "no candidates found" for any gap if the free-distribution market genuinely lacks them.** Do not pad with borderline candidates to fill a quota. Padding has been a recurring failure mode in prior rounds and is the explicit thing we are guarding against.

For EACH typeface candidate you propose, you must explicitly classify quality:
- **STRONG** : verifiable elite usage 2024-2026 (named brand or Awwwards SOTD/HM URL or Fonts In Use entry with brand name) + distinctive character
- **DECENT** : limited but real elite signal (one solid source, distinctive character)
- **BORDERLINE** : acceptable but at risk (popular GF or Fontshare addition, weak distinctiveness, or trajectory toward saturation)
- **NOT_RECOMMENDED** : do not propose

If after exhaustive research you can only find BORDERLINE candidates for a gap, say so explicitly and recommend "accept smaller pool size for this gap" rather than including BORDERLINE entries.

You will be judged on the quality of your conclusions, not the number of candidates you propose. Returning "Gap X — 4 STRONG, 2 DECENT, 0 BORDERLINE — total 6 candidates" with strong evidence is FAR better than returning "Gap X — 12 candidates" with mostly weak proofs.

# THE 3 GAPS — research methodology and output format

For each gap below, follow this method:
1. **Profile the gap precisely** — read the description carefully, understand what register/audace/use is missing
2. **Search systematically** across all source channels (start with Google Fonts post-2023, then Fontshare full catalog, then Velvetyne, then Open Foundry, then GitHub)
3. **Cross-reference each candidate** against priority elite sources (Awwwards, Fonts In Use, It's Nice That, The Brand Identity, Fontshare Inspotype documentation)
4. **Classify each candidate** STRONG / DECENT / BORDERLINE / NOT_RECOMMENDED with explicit reasoning
5. **State honest conclusion**: "found X STRONG + Y DECENT + Z legitimate-but-borderline" OR "no legitimate candidates beyond what is in v3"

## Gap A — Display A1 (sober conservative display)

**Profile** : Display typefaces (use D or DB) suited for **sober conservative briefs** (corporate, institutional, classic editorial, traditional luxury without expressiveness, healthcare conservative, finance traditional). Should be readable at headline size, weight-rich enough for hierarchy, but **distinctive enough to NOT be a generic invisible default**.

**Target** : 10-15 additional candidates.

**Specific sub-needs (registers under-represented in Display A1)** :
- Sub-need A.1 : **Classic serifs sober** (Reg 1 Editorial luxury without dramatic contrast, no didone). E.g., looking for Garamond-quality reissues that are not the banned EB Garamond/Cormorant/Garamond family. Possible candidates to verify: Cardo, IM Fell, Sorts Mill Goudy, Lusitana, Della Respira, Marcellus.
- Sub-need A.2 : **Sans utilitaires premium sober** (Reg 4 Neo-grotesque sober workhorses without becoming SaaS slop). E.g., Public-display tier sans that are NOT in the SLOP_RISK list. Possible candidates: Albert Sans, Mona Sans, Hubot Sans, IBM Plex Sans Condensed (excluded — IBM Plex family banned), Hedvig Letters Sans variants.
- Sub-need A.3 : **Slab display sober** (Reg 8 Slab in display use, currently only Vollkorn covers this). Possible candidates: Roboto Serif (borderline due to Roboto family), Source Serif 4 display variants, Zilla Slab Highlight.

**Honesty checkpoint for Gap A** : Display A1 is hard because most non-slop display typefaces tend toward A2-A3 distinctiveness. If you can only find 5-7 STRONG/DECENT candidates, say so. Don't pad with weak GF additions.

## Gap B — Display A3 (bold modern, NOT decorative extreme)

**Profile** : Display typefaces (use D or DB) for **audacious modern briefs** (creative agency, music, entertainment, festival, cultural institution, modern editorial premium with personality). Should be **distinctive and bold** but NOT in the "pure decorative experimental" register (Reg 12 already saturated with stencil/blackletter/LCD/rotalic).

**Target** : 8-12 additional candidates.

**Specific sub-needs** :
- Sub-need B.1 : **Expressive serif display NOT didone-cliché** (Reg 9 Expressive display alternative beyond Bodoni Moda + Stardom + Recia + Bevellier). E.g., display serifs with character that aren't classic high-contrast revivals. Possible candidates: Crimson Text variants, IM Fell display variants, Vesper Libre, Lusitana display.
- Sub-need B.2 : **Bold sans display with personality NOT brutalist gimmick** (Reg 7 Industrial bold without falling into Reg 12 territory). E.g., bold display sans with structural character, not condensed-Anton-clones. Possible candidates: Bowlby One, Black Ops One, Major Mono Display, Bungee Spice/Hairline.
- Sub-need B.3 : **Geometric expressive sans NOT slop-trajectory** (Reg 11 Geometric expressive needs more options beyond Epilogue + Kola). Possible candidates: Mansalva, Rubik (full family, not just slop variants), Major Mono.

**Honesty checkpoint for Gap B** : Display A3 has fewer free options than Display A1 for this profile. If 6-8 candidates max, that's OK.

## Gap C — Body A3 (audacious legible body — the critical gap)

**Profile** : **Body typefaces (use B or DB)** for audacious briefs that need to remain **readable at body sizes** (10-16px) while having **distinctive character**. This is the hardest gap — bold + legible body + non-slop is mathematically rare in free distribution.

**Target** : 15-25 additional candidates if achievable. **Honest assessment if 8-10 only — accept the limit.**

**Specific sub-needs** :
- Sub-need C.1 : **Mono-spaced body for audacious tech briefs** (beyond what's already in Reg 10). The audacieux brief calls for distinctive monos that work in body length, not just terminal aesthetic. Possible candidates: Departure Mono (Jamie Coulter, free), TX-02 (?), Sentient (already in v3 as WEAK_PROOF — removed), Berkeley Mono (paid — exclude).
- Sub-need C.2 : **Sans humaniste with distinctive character readable at body** (Reg 5 Humanist sans variants beyond what's in v3). Should have one distinctive design feature (ink trap, alternate construction) but remain legible. Possible candidates: Lekton, Petrona variable, Albert Sans variable, Mona Sans bold weights, Recoleta-style sans (free?).
- Sub-need C.3 : **Distinctive serif body for editorial audacieux** (Reg 2 Modern serif extension at A3 audacieux). E.g., serifs with personality readable at body size for editorial bold. Possible candidates: Petrona variable, Bricolage variable text variants, Newsreader at lower opsz with high wght, Rosarivo, Faustina at aggressive weights.
- Sub-need C.4 : **Slab body audacieux** (Reg 8 Slab at A3 — currently 0). Possible candidates: Zilla Slab Bold/Black at body, Bitter Bold at body, Faustina Black at body, Aleo Black at body. Or new candidates: Roboto Slab (excluded — Roboto family ban), Nanum Brush Script (no — too cursive).

**Honesty checkpoint for Gap C** : This gap is structural. The free market has limited options for audacious legible body. If you can return 8-10 STRONG/DECENT candidates, that's already a success. If only 5-6, say so explicitly. Do NOT include BORDERLINE candidates as gap-fill.

**Particular attention** : examine if some Display A3 typefaces in v3 have body-readable alternatives in their family that I missed (e.g., did v3 include Big Shoulders Text for body where Big Shoulders Display is in display? Investigate Display→Text family extensions).
