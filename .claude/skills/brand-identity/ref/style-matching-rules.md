# Règles de matching style — Style × Concept

Ces règles s'appliquent AVANT de shortlister. Elles filtrent les mauvais matchs entre un style officiel reconnu (du catalogue `ref/styles-bibliotheque.md`) et un concept narratif.

Adaptation directe de `ref/font-matching-rules.md` pour le job du sub-agent styliste.

---

## 1. La densité visuelle doit matcher le poids métaphorique

Regarde le style et estime sa **densité visuelle** : quelle quantité de signal visuel tu reçois quand tu vois une vue type (signatures CSS + palette + composition).

- Si le concept évoque la masse, l'ancrage, la rigueur, la gravité → le style DOIT être visuellement dense ou structuré (Brutalism, Editorial Grid, Swiss Modernism 2.0, Neubrutalism…). Un style épuré comme Exaggerated Minimalism est incompatible, même si "minimalisme" sonne raffiné.
- Si le concept évoque la légèreté, l'épure, le souffle, le silence → le style DOIT être épuré (Exaggerated Minimalism, Warmth Minimalism, Hypertypography…). Un style chargé comme Bento Grid Tech ou Gen Z Chaos est incompatible.
- Si le concept évoque la tension, le conflit, la friction → le style peut avoir une densité contrastée (Editorial Grid + accent terracotta vif, Anti-Polish Raw…), mais l'IMPACT GLOBAL doit correspondre à l'intensité de la tension.

## 2. Le registre sensoriel doit correspondre

Quand tu regardes une fiche de style SANS RÉFLÉCHIR (signatures + références culturelles), elle évoque un monde sensoriel précis : luxe éditorial, brutalité industrielle, chaleur artisanale, froideur technique, immersion cinématographique, ferveur Gen Z, etc.

Ce registre sensoriel DOIT correspondre au monde sensoriel du concept. Si le concept parle de **terre** et **silence**, le style doit évoquer la terre et le silence — pas le magazine de mode ni le terminal informatique.

**Test** : ferme les yeux, pense au concept. Ouvre les yeux, lis la description officielle + les références culturelles du style. Est-ce que le monde que tu vois dans le style est le MÊME monde que celui du concept ? Si oui → compatible. Si ce sont deux mondes différents → incompatible, même si tu peux trouver une justification analytique.

## 3. La justification doit être SPÉCIFIQUE, pas générique

Après avoir choisi un style, vérifie ta justification :

**Test de spécificité** : est-ce que ta justification pourrait s'appliquer à 5+ autres styles du catalogue ?
- OUI → ta justification est trop générique → ton choix est probablement un réflexe de famille (le styliste a tiré vers la catégorie la plus évidente sans entrer dans les nuances). Cherche un style dont la justification ne fonctionne QUE pour lui.
- NON → ta justification est spécifique → bon signal.

Exemples de justifications trop génériques (REJET) :
- *"Ce style est moderne et épuré"* → s'applique à 15+ styles
- *"Ce style permet une hiérarchie typographique forte"* → s'applique à tous les éditoriaux et typo-driven
- *"Ce style évite le slop"* → s'applique à 30+ styles ACTUELS du catalogue
- *"Ce style est dans l'air du temps 2026"* → vide stratégiquement

Une bonne justification cite **une signature visuelle unique** de ce style (sa grille 12-cols visible + accent terracotta unique pour Swiss Modernism 2.0, sa lettrine + masthead folio pour Editorial Grid, ses bordures hard 4px + shadow offset 6px sans blur pour Neubrutalism…) et explique pourquoi CETTE signature unique sert CE concept précisément.

## 4. Pas de matching par mots-clés isolés

Le concept contient des mots-clés (extraits des territoires + métaphore narrative). Ne PAS matcher un style sur UN SEUL mot-clé isolé.

**Mauvais matching** : mot-clé *"nature"* → *"je prends Organic Biophilic"*. Trop direct, ne tient pas compte du registre global.

**Bon matching** : le concept DANS SON ENSEMBLE évoque un univers organique, fluide, anti-géométrique → quels styles VIVENT dans cet univers ? (Organic Biophilic ✓, Biomimetic Organic 2.0 ✓, Expressive Organic ✓, Naïve Design selon contexte). Puis arbitrer entre ces 3-4 finalistes par les autres règles.

Les mots-clés orientent le **REGISTRE** général (Éditorial / Brutaliste / Minimaliste / Cinétique / Organique / Cinématographique / Tech / Crafty). Le CHOIX dans ce registre se fait sur l'univers sensoriel global, pas sur un mot-clé.

## 5. Privilégier le feeling global à l'analyse par attributs

Tu peux analyser un style par attributs (densité, registre, palette compatible, signatures). Mais le choix final ne se fait PAS par addition d'attributs ("ce style coche 4/5 critères").

Il se fait par **impression globale** : quand tu lis la fiche complète + tu imagines le rendu sur les ingrédients fixés (palette + fonts), est-ce que ce style SENT comme le concept ?

Si tu hésites entre deux styles qui cochent les mêmes attributs, choisis celui dont l'IMPRESSION GLOBALE est la plus proche du monde du concept — même s'il coche moins de critères analytiques.

## Principes de pairing — Style × Typo × Palette × Concept

Le style retenu ne vit pas en isolation. Il s'incarne avec des INGRÉDIENTS DÉJÀ FIXÉS en amont (typo et palette validées par l'utilisateur en Phase 3B-2 et 3B-3). Le matching style doit donc tenir compte de la cohérence système.

## 6. Cohérence système — même univers sensoriel

Le style choisi + la typo validée + la palette validée doivent former un SYSTÈME cohérent. Ils doivent venir d'un MÊME univers sensoriel, juste avec des rôles différents (le style donne la composition et l'atmosphère, la typo donne la voix, la palette donne le ton émotionnel).

**Test** : imagine le style appliqué à la palette Camille (vert forêt + taupe + terracotta + crème) avec la typo Camille (Bodoni Moda + B612 Mono). Est-ce que les 3 semblent venir d'un même univers ? Ou est-ce qu'on dirait 3 projets différents collés ensemble ?

Exemples d'incohérences :
- Style **Cyberpunk UI** + typo **Cormorant Garamond** + palette **terracotta/crème** = trois mondes qui s'ignorent. REJET.
- Style **Editorial Grid** + typo **Bodoni Moda + B612 Mono** + palette **terracotta/crème** = même monde éditorial papier. ✓

Si le style retenu introduit une dissonance avec la typo OU la palette, le styliste doit reconsidérer son choix (revenir à l'étape de scan et trouver un autre finaliste).

## 7. Contraste structurel — un axe de distinction style/typo

Le style et la typo doivent se distinguer sur AU MOINS un axe structurel pour créer une hiérarchie visuelle vivante. Si les deux sont trop similaires structurellement, le rendu est plat et redondant.

**Axes possibles** :
- Si la typo est minimaliste/géométrique → le style peut être riche/expressif (Editorial Grid, Vintage Analog…)
- Si la typo est expressive/didone → le style peut être dépouillé/structurel (Swiss Modernism 2.0, Exaggerated Minimalism…)
- Si la typo est brutaliste/condensée → le style peut être organique/fluide (Organic Biophilic, Expressive Organic…)
- Si la typo est éditoriale/serif → le style peut être brutal/géométrique (Neubrutalism, Vibrant Block-based…)

**Test** : sur la même page, le style et la typo se renforcent-ils par contraste, ou se confondent-ils par redondance ?

## 8. Le style matche le CONCEPT, pas juste les ingrédients

Le style n'est pas choisi "par rapport à la palette/typo déjà fixées". Il est choisi par rapport au CONCEPT, puis vérifié pour sa cohérence avec les ingrédients (règles 6-7).

Si le concept appelle un registre que les ingrédients ne servent pas bien, c'est un signal qu'il y a un problème EN AMONT (palette ou typo mal choisies pour ce concept), PAS qu'il faut forcer un style "qui marche avec les ingrédients".

Le styliste signale ce signal dans son "Avis du DA" final si la cohérence règles 6-7 est tendue malgré le meilleur style retenu.

## Application opérationnelle

Le styliste applique ces 8 règles dans l'ordre du protocole `ref/styles-matching-protocol.md` :
- **Étape 1** (déclaration TYPE recherché) : règles 1-2-4 orientent le registre cible
- **Étape 2** (scan exhaustif `01-N`) : règles 1-2-4 binarisent COMPATIBLE/INCOMPATIBLE
- **Étape 3** (longlist 6-8 ordonnée) : règle 5 (feeling global) départage
- **Étape 4** (justification) : règle 3 garantit la spécificité
- **Étape 5** (vérif anti-slop final) : règles 6-7-8 vérifient la cohérence système

Si une règle est violée → REJET du candidat, retour à l'étape 2 du protocole.
