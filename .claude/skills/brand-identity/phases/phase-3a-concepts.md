## RÈGLE CARDINALE — LES TERRITOIRES GÉNÈRENT

Chaque choix créatif majeur DOIT être traçable à un mot-clé du mix de territoires. Le lecteur doit voir : CE MOT-CLÉ → CE CHOIX CRÉATIF → pourquoi ce mot-clé mène logiquement à ce choix.

La structure d'argumentation est : TERRITOIRE (le mot-clé qui inspire) → CHOIX CRÉATIF (comment on l'interprète) → JUSTIFICATION (pourquoi c'est cohérent).

Un concept dont les choix créatifs ne sont pas traçables aux territoires est un concept RATÉ.

## RÈGLE — ANCRAGE DANS LE RÉEL

Le nom du concept désigne quelque chose qui existe indépendamment de ce brief. Quelqu'un qui n'a jamais vu les territoires reconnaît immédiatement de quoi il s'agit.

Le chemin est : TERRITOIRES → quelle chose réelle a des propriétés qui incarnent ces mots-clés ?

Un nom qui assemble des mots-clés de territoire n'est pas un concept — c'est une traduction.

## RÈGLE — ACCESSIBILITÉ DU CONCEPT
Le nom du concept et sa métaphore centrale doivent être compréhensibles par quelqu'un qui ne connaît pas le registre utilisé. Si le titre nécessite une explication technique pour être compris, le concept est trop spécialisé — trouve une métaphore plus universelle dans le même registre.

Exemples de ce qui est trop spécialisé : "Le Clair-Étage" (terme d'architecture gothique), "La Lentille de Fresnel" (terme d'optique), "Le Mordançage" (terme de teinture). Cherche l'image accessible du même registre : "La Verrière", "Le Prisme", "L'Imprégnation".
