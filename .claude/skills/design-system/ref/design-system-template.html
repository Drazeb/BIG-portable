Design System

Spécifications visuelles pour les équipes design et engineering : tokens, composants atomiques, règles d'usage. Complète le brand book par tout ce qui est nécessaire à reproduire l'identité de manière conforme.

Test de format 3 sections sur 10 — Color · Typography · Spacing. Les 7 autres (Logo, Iconographie, Dataviz, Photo, Composition, Illustration, Motion) suivront le même gabarit une fois le format approuvé.
01

Color

Palette de 9 couleurs réparties en 4 rôles : base, accent, surface claire, échelle de texte. Système binaire 99/1 — chaque couleur a un usage défini, aucune n'est décorative.

Règle 99 / 1

99 % bleu-marine-nuit, < 1 % Foyer du Phare. Jamais deux accents par vue.

  • 99 % de la surface en Abyss / Night / Marine-Cliff selon densité.
  • < 1 % en Foyer du Phare. Un seul accent chaud par vue, sur intersection de tiers, jamais centré.
  • Pas de pur noir #000000 ni de pur blanc #FFFFFF.

01.4

Don't — anti-direction chromatique

Cinq registres formellement interdits, sourcés §12 du design specs.

  • 01
    Pur noir #000000 comme fond — = dark mode SaaS générique sans personnalité. Toujours teinté Nuit d'Indigo.
  • 02
    Pur blanc #FFFFFF comme texte — contraste violent amateur. Toujours Encre de Veille Bleutée.
  • 03
    Indigo / violet / purple gradient nulle part — l'accent unique est Foyer du Phare orange. Vérifier qu'aucun hover/focus ne dérive vers un indigo Tailwind par réflexe.
  • 04
    Bleu cyan / électrique — = ventre mou conseil stratégique digital (BCG, Bain digital).
  • 05
    Gradient mesh sur le fond global — = papier peint SaaS cyclique. Le fond global est un aplat teinté Nuit d'Indigo ; les halos sont des incrustations radiales locales.
02

Typography

Pairing à 2 familles : Gloock pour le display, JetBrains Mono pour tout le reste (body, captions, eyebrows, données, navigation). 7 tailles dans le type scale, dont une échelle hero hypertrophiée pour les ouvertures (clamp jusqu'à 22vw).

02.1

Pairing stratégique

Deux familles strictement, aucune troisième fonte. Pas de fallback sans-serif générique sur les titres (Times New Roman en stack uniquement).

Monospace, 5 graisses + italic. Usage : body, captions, eyebrows, numérotations (05.1, Chapitre · V), labels documentaires, coordonnées, data, navigation, CTA.

02.4

Don't — anti-direction typographique

Quatre registres formellement interdits, sourcés §03.1 et §12.4 du design specs.

  • 01
    Inter / Helvetica par défaut — Gloock + JetBrains Mono déjà figés, jamais de fallback corporate.
  • 02
    Variable fonts animées kinétiques — Gloock et JetBrains Mono ne sont pas des typographies en mouvement.
  • 03
    Troisième fonte — le pairing est fermé. Pas de fallback sans-serif générique sur les titres (Times New Roman en stack uniquement).
  • 04
    Manifesto poétique pollution narrative — texte exigeant, lucide, jamais ronflant ni inspirationnel.
03

Spacing

Échelle 8px à progression Fibonacci, 8 tokens de 4px à 168px. Densité binaire — un mode aéré pour les sections charnières (hero, manifesto), un mode compact pour les zones documentaires (tables, listings). Pas de valeur intermédiaire.

03.1

Échelle — 8 tokens

Toute valeur d'espacement utilise un de ces 8 tokens. Pas d'interpolation, pas de valeur libre en pixels — choisir le token le plus proche du besoin.

--space-2xs4px
Hairlines verticales, gap inter-icônes.
--space-xs8px
Gap éléments denses, séparation tabulaire.
--space-sm16px
Padding interne compact.
--space-md24px
Padding standard documentaire.
--space-lg40px
Inter-blocs documentaires.
--space-xl64px
Padding section dense.
--space-2xl104px
Padding section aérée.
--space-3xl168px
Padding section charnière hero / manifesto.
03.2

Stratégie de densité — binaire

Deux modes seulement. Toute zone se classe en aéré-charnière OU en compact-documentaire. Ratio entre les deux : ~3.5×.

ModePadding blocLine-heightMax-inline-sizeUsage
Aéré · charnière 7vw / 112px max 1.85 32ch Manifestes, ouvertures de chapitre, hero. Un seul propos par bloc.
Compact · documentaire 24px fixe 1.3 100% Tableaux, coordonnées, listings, data dense.
03.3

Don't — anti-direction spatiale

Le design specs §08.2 ne pose qu'une seule interdiction explicite sur l'espacement.

  • 01
    Padding intermédiaire entre aéré-charnière et compact-documentaire — la modération molle est l'erreur. Deux densités, jamais entre les deux.
